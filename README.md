# 假人盾构机 1.1.0

**AI 声明：本项目完全由 OpenAI Codex 开发。**

[English](README.en.md)

Minecraft Java 版 26.3 Fabric 客户端模组，通过服务端 Carpet `/player` 命令，让有限名字的假人依次处理水平矩形内的方块。

## 安装

将 `build/libs/fake-player-tbm-1.1.0.jar` 放入 26.3 Fabric 实例的 `mods` 文件夹，删除旧版，同时安装 Fabric API。需要 Fabric Loader 0.19.5 或更高版本和 Java 25。

服务端（单人世界即本地服务端）必须安装支持 26.3 的 Carpet，且玩家有权限使用 `/player`。在线模式服务器可能要求名字对应真实账号，或由管理员开启 `allowSpawningOfflinePlayers`；白名单和玩家数量限制等也可能阻止召唤。请先手动测试 `/player TBM_1 spawn` 和 `/player TBM_1 kill`。整个任务期间请保留名字池，避免其他玩家或任务使用相同名字。

## 图形界面

在聊天栏输入 `/faketbm` 或 `/faketbm gui` 打开界面，填写两个角的 X/Z、目标方块的 Y 高度、名字前缀、假人数量、每次工作的秒数，然后选择“保存并开始”。“停止”停止分配新位置并清理已召唤的假人。

例如 X1=0、Z1=0、X2=9、Z2=4、Y=64，前缀 `TBM_`、数量 3、时间 30，表示依次处理 50 个坐标，用 `TBM_1` 至 `TBM_3` 三个名字，每次持续攻击 30 秒。范围两端都包含。Minecraft 水平轴是 X/Z，Y 是高度；假人脚部生成在方块上方 `(x+0.5, y+1, z+0.5)`。

也可使用命令：

```text
/faketbm area 0 0 9 4 64
/faketbm config TBM_ 3 30
/faketbm start
/faketbm status
/faketbm stop
/faketbm resume
```

名字前缀只能含英文字母、数字和下划线，完整名字最多 16 字符；数量为 1–100，秒数为 1–86400。任务每个坐标处理一次，所有位置分配后等待假人清理完毕即结束。

## 自动恢复和限制

- 假人提前离线时，保留其当前位置，等待后使用同一名字重试；召唤未上线或清理未下线时会定时重试，其他假人继续处理。在线但不属于当前任务的名字会等待释放。指令没有权限或名字不能生成时会一直重试，请查看服务端反馈。
- 假人实体在客户端可见时，若其水平位置偏离目标中心超过 1.5 格，会尝试清理并重新处理该位置。远处或其他维度实体未加载时无法检测其位置，模组不会将不可见视作离线；上下坠落不触发偏移重试。
- 玩家切换维度时，新召唤暂停，切回任务所在维度后继续；已在线假人的控制和清理仍会尝试执行。断线后任务保留在**当前客户端进程的内存中**，重连并确认进入原服务器及世界后，按“确认原服后恢复”或执行 `/faketbm resume`。模组无法核实服务器是否为原来的世界，请勿在其他服务器恢复。关闭游戏会丢失任务，假人可能需要手动清理。
- 客户端必须保持在线才能调度。断线、游戏退出或服务器拒绝指令时无法保证清理；需要时手动执行 `/player 名字 kill`。停止期间尚未确认上线的召唤超时后会放弃等待；异常延迟才上线的假人可能需要手动清理。
- 最多每 20 客户端 tick 发送一条命令。持续时间使用客户端 tick，不保证与实际服务器时间一致；服务端延迟或拒绝命令可能影响效果。假人游戏模式由 Carpet 默认行为决定。本模组不提供工具，也不检查方块是否已经被挖掉。

## 构建和测试

先设置 `MC_DIR` 环境变量，指向 Minecraft 游戏目录，再运行 `./build.sh`。脚本需要 JDK 25，以及 `versions/26.3-Fabric/26.3-Fabric.jar`、`versions/26.3-Fabric/mods/fabric-api-0.160.5+26.3.jar` 和该目录下的游戏依赖。`./test.sh` 使用模拟连接测试调度，不替代游戏内测试。

命令参考：[Carpet 官方命令文档](https://github.com/gnembon/fabric-carpet/wiki/Commands)；工具链参考：[Fabric 26.3 发布说明](https://fabricmc.net/2026/09/15/263.html)。
